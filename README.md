# NovaTrend — интернет-магазин одежды

Витрина, корзина, оформление заказа с геолокацией и телефоном/WhatsApp,
админка и база данных — всё работает на Netlify.

## Что внутри

| Часть | Где | Что делает |
|---|---|---|
| Витрина | `public/index.html` | Главная по макету: категории, новинки, хиты, распродажа с таймером, каталог с фильтрами и поиском, избранное |
| Корзина | выезжает справа | Размеры, количество, прогресс до бесплатной доставки |
| Оформление | `public/checkout.html` | Имя, телефон, WhatsApp, способ связи, курьер/самовывоз, адрес, **кнопка «Отправить моё местоположение»** (точка на карте), оплата |
| Админка | `/admin` | Заказы (статусы, звонок/WhatsApp/Telegram в один клик, карта), товары (добавить/изменить/скрыть/удалить), настройки доставки |
| База данных | Netlify Blobs | Каталог, настройки и заказы. Создаётся автоматически, настраивать не нужно |
| API | `netlify/functions/*.mjs` | `/api/products`, `/api/orders` |

Цены и сумма заказа всегда пересчитываются на сервере — подменить цену из браузера нельзя.

## Запуск на Netlify

> Важно: перетаскивание папки в Netlify (Drag & Drop) **не подключает функции**.
> Используйте GitHub или Netlify CLI.

### 1. Залейте сайт

**Вариант А — через GitHub (удобнее):**
1. Загрузите эту папку в новый репозиторий на GitHub.
2. Netlify → **Add new site → Import an existing project** → выберите репозиторий.
3. Настройки сборки подтянутся из `netlify.toml` сами. Нажмите **Deploy**.

**Вариант Б — через терминал:**
```bash
npm install
```
```bash
netlify login
```
```bash
netlify deploy --prod
```

### 2. Задайте пароль админки
Netlify → ваш сайт → **Site configuration → Environment variables**:

| Переменная | Значение |
|---|---|
| `ADMIN_PASSWORD` | пароль для входа в админку (придумайте сложный) |

После добавления переменных сделайте **Deploys → Trigger deploy**.

Готово: новые заказы появляются в админке (`/admin`), она обновляется сама и подаёт звуковой сигнал.

## Как менять магазин

- **Товары, цены, фото** — в админке, вкладка «Товары». Фото — ссылка на картинку (например, с Unsplash или из вашего хостинга).
- **Стоимость доставки, порог бесплатной доставки, валюта, адрес самовывоза, телефон, WhatsApp, дата конца распродажи** — админка → «Настройки».
- **Стартовый каталог** (до первого изменения в админке) — `public/data/products.json`.
- **Цвета** — переменные в начале `public/css/style.css` (`--accent` — оранжевый).
- **Тексты главной** — `public/index.html`.

## Локальный запуск

```bash
npm install
```
```bash
netlify dev
```
Создайте файл `.env` с `ADMIN_PASSWORD=...`. Сайт откроется на `http://localhost:8888`.
